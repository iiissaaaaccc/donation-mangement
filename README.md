## Donation Management Platform ##


## About the Project
A donation function of a web application for tct.sg. This is a Tampines Chinese Temple website where users are able to see events happening in the temple, as well as donate to the temple or give thier blessings to others.

## My Role
Developer for the donation and payment functions on the website.

## Technologies Used
- Next.js
- TypeScript
- Supabase
- Vercel

## Features I Developed
Document the features you personally implemented,
such as:

### 1. MFA for Admin Account
- Created multifactor authentication for the admin account
- Besides using password, users will also need to enter a code that is sent to their email
- Email triggering and formatting are handled by Supabase

### 2. Edit Blessing Through Admin Account
- Admins are able to manage the blessings displayed on the home page
- Functions include deleting, creating and editing the information displayed on the blessing page

### 3. Administrative Features
- Managing donation events
- Restricting administrative operations

### 4. Notifications and Receipts
- Donation enquiry notifications
- Generating PDF receipts
